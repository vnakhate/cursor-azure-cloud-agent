Blueprint · without JWT gateway

Cursor Firecracker → Azure

Managed Cloud Agents stay on Cursor AWS (Firecracker). Private Azure is reached via Cloudflare Tunnel + Access and Entra federation on team_id — not by spawning agents inside your VNet, and not by allowlisting shared Cursor egress IPs.

Two paths, one org lock

Identity: OIDC → Entra → Azure APIs Network: Access → cloudflared → private apps

Do

  • Lock Allowlist-only egress

  • Put agents on the Mac
  • Expect this to stop prompt injection
